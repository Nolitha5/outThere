# OutThere

OutThere is a responsive event booking demo for the Sqrock IT Solutions web development internship. It showcases fictional Cape Town events using HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` in a browser. For a local server, run `python -m http.server 4173` from this folder and visit `http://localhost:4173`. No dependencies or build step are needed.

## Task 3 brief

The platform lets users discover upcoming events, see what to expect and submit a booking or registration request. The project exercises frontend development, responsive layout, UI/UX, dynamic listings, and form handling and validation.

- The homepage features a hero, a featured event, category controls and booking links.
- Listings show a poster, event name, date and time, venue, ticket price and short description.
- Each event has its own link with a description, schedule, organizer contact, venue address and ticket information.
- Search matches event names. Category, month and indoor/outdoor filters combine with search.
- Booking collects name, email, phone, event and quantity. It validates input and updates the total.
- Navigation and the contact footer work on mobile, tablet and desktop.

The brief offers sign-in and sign-up UI, a countdown, a confirmation page, payment UI, a categories page, dark mode, animation and an admin dashboard UI. This project implements the **confirmation page**. It displays a reference and ticket summary and survives a refresh in the same tab using session storage. Contact details are discarded on submission. Events and bookings are simulated, and no payment is collected.
